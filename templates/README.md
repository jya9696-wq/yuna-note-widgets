## yuna-skill — 학생 '내 능력치' 레이더 위젯 (한 달에 한 번 갱신)
- `../yuna-skill.html?d=2026.10&now=4,3,4,2,4,3,3,4&prev=3,3,3,2,4,2,2,4&pc=지난코멘트&nc=지금코멘트`
- 숫자 순서: 비율·입체감·선화·채색(주 능력치) / 얼굴·눈·앵글·동세·배경·디자인·콘셉트(부가 능력치)
- 열면 그래프가 차오르고, 가운데에 종합 레벨(평균). "지난 능력치"·"지금 능력치"를 누르면 그쪽이 강조되며 코멘트가 4.5초 떴다가 사라짐.
- 선생님용 수정 화면: 같은 주소 끝에 `&e=1` → 꼭짓점 끌기·숫자·코멘트 수정 후 "새 주소 복사".

## yuna-note-cards.html — 필기노트 맨 위 카드 3칸 (상호작용)
학생 페이지 카드(yuna-cards)와 같은 디자인·호버. 노트마다 주소만 바꿔서 임베드.
`yuna-note-cards.html?v=영상ID&a=0.02.14-0.42.24&b=다음과제(10자, 주소 인코딩)&bt=초&p=지난노트ID&pd=10.10`
- 주의: 노션 임베드 주소에 `:` `~` `/` 를 넣으면 빈 칸이 됨 → `.` `-` 와 초 단위 사용
- 1번 내 피드백 구간 → a의 시작 시간부터 영상(새 탭)
- 2번 다음 과제 → bt 시간 영상(새 탭)
- 3번 지난 피드백 → 지난 노트(같은 탭)
